## BreadcrumbsProps

| Prop | Type | Default | Description |
|---|---|---|---|
| `items *` | `BreadcrumbItem[]` | — | Trail from the root to the current page. The last item is the current page. |
| `maxItems` | `number` | `4` | Collapse the middle into a "…" menu when there are more items than this. |
| `separator` | `BreadcrumbSeparator` | `"chevron"` | "chevron", "slash" or any node (e.g. an icon). |
| `itemsBeforeCollapse` | `number` | `1` | Items kept before the "…" when collapsed. |
| `itemsAfterCollapse` | `number` | `2` | Items kept after the "…" when collapsed. At least 1, so the current page stays visible. |
| `renderLink` | `(props: BreadcrumbLinkProps) => ReactNode` | `defaultRenderLink` | Renders every link, e.g. `(p) => <Link {...p} />` for next/link. Defaults to a plain anchor. |
| `showHomeIcon` | `boolean` | `false` | Show a house icon on the first item (unless it has its own icon). |
| `homeIconOnly` | `boolean` | `false` | With showHomeIcon, hide the first item's label visually (it stays readable by screen readers). |
| `mobileBackLink` | `boolean` | `false` | Below ~448px of available width, replace the trail with a compact "← Parent" link. |
| `backLabel` | `(parent: BreadcrumbItem) => string` | `(p) => p.label` | Visible text of the compact back link. |
| `backAriaLabel` | `(parent: BreadcrumbItem) => string` | `(p) => `Back to ${p.label}`` | Accessible name of the compact back link. |
| `label` | `string` | `"Breadcrumb"` | Accessible name of the nav landmark. |
| `expandLabel` | `(hiddenCount: number) => string` | `(n) => `Show ${n} more`` | Accessible name of the "…" button. |
| `maxLabelWidth` | `string` | `"12rem"` | Labels with more characters than this width are truncated with a tooltip. Any CSS length. |
| `loading` | `boolean` | `false` | Show a skeleton trail while the path is resolving. |
| `loadingLabel` | `string` | `"Loading breadcrumb"` | Announced while loading. |
| `loadingCount` | `number` | `3` | Number of skeleton crumbs. |
| `siblingsLabel` | `(item: BreadcrumbItem) => string` | `(item) => `Other items next to ${item.label}`` | Accessible name of a sibling menu button and list. |
| `siblingFilterThreshold` | `number` | `7` | Sibling menus with more items than this get a filter box. |
| `siblingFilterLabel` | `string` | `"Filter…"` | Placeholder and name of the filter box. |
| `noMatchesLabel` | `string` | `"No matches"` | Shown when the filter matches nothing. |
| `className` | `string` | — | — |
