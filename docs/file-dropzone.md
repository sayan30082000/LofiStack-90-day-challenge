# File Dropzone

> Week 06 · `form` · #18

Dropzone that checks files first: strips GPS from photos, flags blurry or small images, shrinks big ones, checks CSV columns.

- Live demo: https://lofistack-sayan.netlify.app/components/file-dropzone
- Source: https://github.com/sayan30082000/LofiStack-90-day-challenge/blob/main/components/ui/file-dropzone.tsx
- Build prompt: https://lofistack-sayan.netlify.app/components/file-dropzone#prompt
