# Logo Marquee

> Week 07 · `section` · #60

Logo strip that sizes every logo optically, so wide, tall, thin and heavy logos look equally big.

- Live demo: https://lofistack-sayan.netlify.app/components/logo-marquee
- Source: https://github.com/sayan30082000/LofiStack-90-day-challenge/blob/main/components/ui/logo-marquee.tsx
- Build prompt: https://lofistack-sayan.netlify.app/components/logo-marquee#prompt

```tsx
import { LogoMarquee } from "@/components/ui/logo-marquee";
```

## LogoMarqueeProps

| Prop | Type | Default | Description |
|---|---|---|---|
| `items *` | `LogoMarqueeItem[]` | — | Logos to scroll. With rows > 1 they are split into that many rows, in order. |
| `pxPerSecond` | `number` | `40` | Speed in pixels per second. Every row moves at this speed whatever its length, so rows with different numbers of logos stay in step. |
| `speed` | `number` | — | Seconds for one full loop instead of pxPerSecond. Rows of different lengths then move at different speeds. |
| `direction` | `LogoMarqueeDirection` | `"left"` | Direction of the first row. "up" and "down" make a vertical marquee. |
| `pauseOnHover` | `boolean` | `true` | Pause while the pointer is over the marquee. It always pauses while a link inside has keyboard focus. |
| `draggable` | `boolean` | `true` | Let people grab a row and drag it to scrub through the logos. |
| `fade` | `boolean` | `true` | Fade the edges with a mask. |
| `fadeSize` | `number` | `64` | Width (or height, when vertical) of the fade, in px. |
| `gap` | `number` | `48` | Space between logos, in px. |
| `rows` | `number` | `1` | Number of rows (columns when vertical). Every other row moves the opposite way. |
| `grayscale` | `boolean` | `true` | Show logos in grayscale and bring color back on hover or focus. |
| `logoHeight` | `number` | `28` | Height of image logos, in px. With `normalize`, this is the height a typical 3:1 wordmark gets; other shapes are sized to look as big. |
| `normalize` | `boolean` | `true` | Optical sizing: measure each image logo's visible ink (trimming transparent or flat padding) and size it so wide, tall, thin and heavy logos all look the same size. |
| `height` | `number` | `320` | Height of the marquee when vertical, in px. |
| `title` | `ReactNode` | — | Optional heading shown above the strip, e.g. "Trusted by teams at". Also names the region. |
| `label` | `string` | `"Logos"` | Accessible name of the region when there is no title. |
| `showControls` | `boolean` | `true` | Show a pause/play button (recommended: hover alone doesn't help keyboard or touch users). |
| `pauseLabel` | `string` | `"Pause logo animation"` | Accessible label of the control while playing. |
| `playLabel` | `string` | `"Play logo animation"` | Accessible label of the control while paused. |
| `className` | `string` | — | Classes for the outer section. |
| `itemClassName` | `string` | — | Classes for each logo cell. |
