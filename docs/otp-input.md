# OTP Input

> Week 05 · `input` · #7

Code boxes you can paste a whole SMS into: finds the code, with WebOTP, expiry and resend cooldown.

- Live demo: https://lofistack-sayan.netlify.app/components/otp-input

- Build prompt: https://lofistack-sayan.netlify.app/components/otp-input#prompt
