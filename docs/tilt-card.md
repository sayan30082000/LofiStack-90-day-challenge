# 3D Tilt Card

## TiltCardProps

| Prop | Type | Default | Description |
|---|---|---|---|
| `children *` | `ReactNode` | — | Card content. Any descendant with a `data-depth` attribute (in px, e.g. `data-depth="40"`) lifts off the surface by that much while the card is active, for a parallax effect. |
| `maxTilt` | `number` | `12` | Maximum rotation on each axis, in degrees. |
| `glare` | `boolean` | `true` | Show a highlight that follows the pointer. |
| `glareColor` | `string` | `"rgb(255 255 255 / 0.55)"` | Any CSS color for the glare highlight's center. |
| `scale` | `number` | `1.03` | Scale while hovered. Pressing shrinks it slightly for an active state. |
| `perspective` | `number` | `1000` | CSS perspective distance in px. Lower values look more dramatic. |
| `shadow` | `boolean` | `true` | Soft drop shadow that drifts away from the pointer. |
| `resetDuration` | `number` | `600` | Duration of the ease back to rest when the pointer leaves, in ms. |
| `disabled` | `boolean` | `false` | Turn the effect off; children render as a flat card. |
| `className` | `string` | — | Classes for the tilting surface (background, radius, size, padding). Avoid overflow-hidden here: it flattens depth layers. |
| `wrapperClassName` | `string` | — | Classes for the untransformed outer wrapper (layout, width, margins). |
| `motion` | `boolean` | `true` | On phones and tablets, tilt the card by tilting the device. Calibrates to how it's held when motion starts. iOS asks for permission once, through a small "Enable motion" button. |
| `motionLabel` | `string` | `"Enable motion"` | Label of the button that asks for motion permission on iOS. |
| `light` | `"pointer" \| TiltLight` | `"pointer"` | Where the light comes from. "pointer": the glare follows the pointer. A point ({ x, y } from -1 to 1, e.g. { x: -0.5, y: -0.8 } for top left) is a fixed lamp: the reflection slides across the card as it tilts and the shadow falls away from the light, like a real card under a light. |
