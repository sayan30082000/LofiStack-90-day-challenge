# Toast System

> Week 10 · `modal` · #35

Toasts that merge repeats (×3), stay long enough to read, and undo with Ctrl/⌘+Z before committing.

## ToastOptions

Options for toast(message, options) and its variants.

| Prop | Type | Default | Description |
|---|---|---|---|
| `description` | `ReactNode` | — | Secondary line under the message. |
| `action` | `ToastAction` | — | Optional action button, e.g. Undo. |
| `duration` | `number` | — | Milliseconds before it closes on its own. Infinity keeps it open. Defaults to the Toaster's duration. |
| `id` | `string` | — | Pass an existing id to update that toast in place instead of stacking a new one. |
| `dismissible` | `boolean` | — | Show the close button and allow swipe to dismiss. |
| `onDismiss` | `(id: string) => void` | — | Called when the toast is closed by the user (button, swipe, Escape) or by toast.dismiss(). |
| `onAutoClose` | `(id: string) => void` | — | Called when the toast closes because its timer ran out. |
| `group` | `string \| false` | — | Toasts with the same group merge into one instead of stacking, e.g. "upload". Without a group, a toast with exactly the same type and text as one on screen merges with it (shown as ×2, ×3…). Pass false to always stack. |
| `groupMessage` | `(count: number, latest: ReactNode) => ReactNode` | — | Message of a merged toast, from how many were merged and the newest message. |

## ToastUndoOptions

Options for toast.undo().

_extends Omit<ToastOptions, "action" | "group" | "groupMessage">_

| Prop | Type | Default | Description |
|---|---|---|---|
| `onUndo *` | `() => void` | — | Puts things back. Runs instead of onCommit when Undo (or Ctrl/⌘+Z) is pressed in time. |
| `onCommit` | `() => void` | — | Makes the change permanent. Runs once when the toast closes any other way. |
| `undoLabel` | `string` | — | Text of the undo button. |
| `undoneMessage` | `ReactNode` | — | Message shown after undoing. Empty shows nothing. |

## ToastProps

Props of the <Toaster /> that renders every toast.

| Prop | Type | Default | Description |
|---|---|---|---|
| `position` | `ToastPosition` | `"bottom-right"` | Corner or edge of the viewport the stack grows from. |
| `max` | `number` | `3` | Toasts visible at once. Older ones wait and move up as newer ones close. |
| `duration` | `number \| "auto"` | `"auto"` | Default auto-dismiss time in ms, or "auto" to give each toast time to be read: about 0.3s per word on top of 3s, between 4s and 15s. Loading toasts never auto-dismiss. |
| `expand` | `boolean` | `false` | Always show the stack expanded instead of only on hover or focus. |
| `closeButton` | `boolean` | `true` | Show a close button on every dismissible toast. |
| `showProgress` | `boolean` | `true` | Show the countdown bar along the bottom edge. |
| `gap` | `number` | `10` | Gap between expanded toasts, in px. |
| `peek` | `number` | `14` | How much each collapsed toast peeks out behind the front one, in px. |
| `offset` | `number` | `16` | Distance from the viewport edges, in px. |
| `width` | `number` | `360` | Toast width in px. Capped to the viewport on small screens. |
| `swipeThreshold` | `number` | `64` | Horizontal drag distance in px that dismisses a toast. |
| `hotkey` | `string` | `"F8"` | Key (KeyboardEvent.key) that moves focus to the newest toast. |
| `label` | `string` | `"Notifications"` | Accessible name of the region. The hotkey is appended. |
| `dismissLabel` | `string` | `"Dismiss notification"` | Accessible name prefix of close buttons. The toast message is appended when it is text. |
| `clearAllLabel` | `string` | `"Clear all"` | Text of the button that closes every toast, shown while the stack is expanded. Empty hides it. |
| `icons` | `Partial<Record<ToastType, ReactNode>>` | — | Replace the icon of any toast type. |
| `zIndex` | `number` | `100` | Stacking order of the region. |
| `toastClassName` | `string` | — | Classes for every toast card. |
| `undoShortcut` | `boolean` | `true` | Ctrl+Z / ⌘Z undoes the newest toast.undo() on screen (not while typing in a field). |
